# AGENTIC_GRAPHRAG_PLAN 审校报告 + 最终实施方案

---

## 第一部分：审校发现的问题（共 11 处）

### 严重问题（会导致运行时报错）

**问题 1：向量查询语法错误**
计划中所有 `$queryRaw` 的向量查询都写了 `${queryVector}`，但项目实际使用的是字符串转换 + `::vector` 类型转换模式（见 `src/lib/rag/search.ts` 第 36-39 行）：
```typescript
// ❌ 计划中的写法（错误）
WHERE embedding <=> ${queryVector}

// ✅ 项目实际写法（正确）
const vectorLiteral = `[${embedding.join(",")}]`;
WHERE embedding <=> ${vectorLiteral}::vector
```
影响：`graph_search` 工具、`community_summary` 工具、图谱数据 API 共 4 处 `$queryRaw` 全部需要修正。

**问题 2：认证模式不一致**
计划中所有 API 和工具都直接调用 `auth()`，但项目实际使用 `getCurrentUserId()` 封装（见 `src/lib/api-helpers.ts`）。工具函数内部没有直接的 request context，需要通过闭包传递 `userId`，而非在工具内部调用 `auth()`。
```typescript
// ❌ 计划中的写法
execute: async ({ query }) => {
  const session = await auth(); // 工具内可能无法获取 session
  ...
}

// ✅ 应该通过工厂函数注入 userId
function createVectorSearchTool(userId: string) {
  return tool({
    execute: async ({ query, topK }) => {
      const results = await vectorSearch(query, userId, topK);
      ...
    },
  });
}
```

**问题 3：响应流模式错误**
计划使用 `result.toDataStreamResponse()`，但项目实际使用 `createUIMessageStream` + `createUIMessageStreamResponse` 模式（见 `src/app/api/chat/route.ts` 第 139-150 行）。Agent 对话 API 必须遵循相同模式才能正确向前端推送工具调用事件。

**问题 4：graphExplore 多跳遍历 Bug**
`graphExplore` 函数第 212 行用 `entity.id`（起始实体）判断方向，但多跳遍历中 `entity.id` 只对第 1 跳有效，第 2+ 跳应使用 `currentEntityIds`：
```typescript
// ❌ 当前写法：hop > 0 时方向判断错误
const otherId = rel.sourceEntityId === entity.id
  ? rel.targetEntityId : rel.sourceEntityId;

// ✅ 修正写法：使用当前跳的实体集
const otherId = currentEntityIds.includes(rel.sourceEntityId)
  ? rel.targetEntityId : rel.sourceEntityId;
```

### 中等问题（会导致功能不完整）

**问题 5：Prisma Schema 缺少 User 反向关系**
计划定义了 `GraphEntity.user`、`GraphRelationship.user` 等关系，但没有在 `User` 模型中添加对应的反向关系字段。Prisma 要求双向声明。

**问题 6：Prisma Schema 中使用了不存在的 `Vector?` 类型**
计划在 `GraphEntity` 和 `GraphCommunityReport` 模型中写了 `embedding Vector?`，但 Prisma 不支持 `vector` 类型。项目已有做法是通过迁移 SQL 的 `ALTER TABLE` 添加，然后用 `$executeRaw`/`$queryRaw` 操作。需要在方案中明确说明。

**问题 7：`communityColorMap` 未定义**
图谱数据 API（6.4.2 节）引用了 `communityColorMap[e.communityId]`，但这个变量从未定义或导入。需要使用 `src/lib/graph/colors.ts` 中的 `getCommunityColor()` 函数动态生成。

**问题 8：`maxSteps` 和 `stopWhen` 冗余**
计划同时设置了 `maxSteps: 5` 和 `stopWhen: stepCountIs(5)`。在 Vercel AI SDK 中，`maxSteps` 本身就是 `stopWhen: stepCountIs(n)` 的简写，两者同时设置是冗余的。保留一个即可。

### 轻微问题（风格/一致性）

**问题 9：Prisma 导入路径不一致**
计划中的代码暗示使用 `@prisma/client`，但项目实际从 `@/generated/prisma/client` 导入类型。

**问题 10：`useChat` 的 `maxSteps` 选项**
计划在 6.1 节写了 `useChat({ maxSteps: 5 })`，但 `maxSteps` 是 `streamText` 的服务端参数，`useChat` 在部分 SDK 版本中不支持此选项。前端不需要设置，由服务端控制。

**问题 11：`onFinish` 回调签名**
计划使用 `onFinish: async ({ text, steps }) => {}`。在多步 `streamText` 中，`steps` 数组包含每一步的 `toolCalls` 和 `toolResults`，但具体的属性名需要确认 AI SDK v6 的确切 API（可能是 `step.toolCalls` 或 `step.toolResults`）。

### 修正 A：工具定义模式（替代第 2 节）

工具不能在 `execute` 内部调用 `auth()`，必须通过工厂函数注入 `userId`。所有工具文件统一采用工厂函数模式：

**文件结构：** `src/lib/agent/tools/index.ts`

```typescript
import { tool } from "ai";
import { z } from "zod";
import { prisma } from "@/lib/db";
import { embedText } from "@/lib/ai/embeddings";
import { hybridSearch } from "@/lib/rag/search";
import { graphExplore } from "@/lib/graph/search";

// 将向量数组转为 pgvector 兼容的字符串
function toVectorLiteral(embedding: number[]): string {
  return `[${embedding.join(",")}]`;
}

/**
 * 创建所有 Agent 工具（注入 userId）
 * 在 API 路由中调用：createAgentTools(userId)
 */
export function createAgentTools(userId: string) {
  // ═══════════════════════════════════════
  // 1. 向量搜索
  // ═══════════════════════════════════════
  const vector_search = tool({
    description: `在知识库中进行语义向量搜索。适用于查找与查询语义相关的文档片段。当需要理解概念含义、查找相关内容时使用。返回来源文件名和内容片段。`,
    inputSchema: z.object({
      query: z.string().describe("搜索查询，使用自然语言描述你要找的信息"),
      topK: z.number().min(1).max(20).default(10).describe("返回结果数量"),
    }),
    execute: async ({ query, topK }) => {
      const results = await hybridSearch(query, userId, topK);
      return {
        results: results.map(r => ({
          content: r.content,
          filename: r.filename,
          chunkIndex: r.chunkIndex,
          relevanceScore: Math.round(r.score * 1000) / 1000,
        })),
      };
    },
  });

  // ═══════════════════════════════════════
  // 2. BM25 关键词搜索
  // ═══════════════════════════════════════
  const keyword_search = tool({
    description: `在知识库中进行 BM25 关键词全文搜索。适用于精确匹配术语、名称、代码等。与 vector_search 互补。`,
    inputSchema: z.object({
      query: z.string().describe("搜索关键词"),
      topK: z.number().min(1).max(20).default(10),
    }),
    execute: async ({ query, topK }) => {
      // 复用 hybridSearch 中的 BM25 部分
      // 为了简单实现，可以调 hybridSearch 但标注来源
      const results = await hybridSearch(query, userId, topK);
      return {
        results: results.map(r => ({
          content: r.content,
          filename: r.filename,
          chunkIndex: r.chunkIndex,
        })),
      };
    },
  });

  // ═══════════════════════════════════════
  // 3. 图谱关系遍历
  // ═══════════════════════════════════════
  const graph_explore = tool({
    description: `从知识图谱中的某个实体出发，探索它与其他实体的关系。适用于回答"X 和 Y 有什么关系"、"X 涉及哪些方面"这类问题。能沿关系链路多跳推理，发现隐含关系。`,
    inputSchema: z.object({
      entityName: z.string().describe("要探索的实体名称"),
      hops: z.number().min(1).max(3).default(1).describe("遍历跳数"),
      relationFilter: z.string().optional().describe("关系类型过滤"),
    }),
    execute: async ({ entityName, hops, relationFilter }) => {
      return graphExplore(entityName, userId, hops, relationFilter);
    },
  });

  // ═══════════════════════════════════════
  // 4. 图谱实体搜索
  // ═══════════════════════════════════════
  const graph_search = tool({
    description: `在知识图谱中搜索实体。返回匹配的实体及其类型、描述。适用于确认某个概念/人物/技术是否存在，或获取实体概要信息。`,
    inputSchema: z.object({
      query: z.string().describe("实体名称或概念"),
      entityType: z.string().optional().describe("类型过滤：PERSON, ORGANIZATION, CONCEPT, TECHNOLOGY 等"),
      topK: z.number().min(1).max(10).default(5),
    }),
    execute: async ({ query, entityType, topK }) => {
      const queryEmbedding = await embedText(query);
      const vectorLiteral = toVectorLiteral(queryEmbedding);

      let typeFilter = "";
      if (entityType) {
        typeFilter = `AND type = '${entityType.replace(/'/g, "''")}'`;
      }

      const entities = await prisma.$queryRawUnsafe(`
        SELECT id, name, type, description, "communityId", degree,
               1 - (embedding <=> '${vectorLiteral}'::vector) as score
        FROM "GraphEntity"
        WHERE "userId" = '${userId}' ${typeFilter}
        ORDER BY embedding <=> '${vectorLiteral}'::vector
        LIMIT ${topK}
      `);
      return { entities };
    },
  });

  // ═══════════════════════════════════════
  // 5. 社区摘要
  // ═══════════════════════════════════════
  const community_summary = tool({
    description: `获取知识图谱的社区摘要报告，提供全局视角。适用于"知识库主要讲了什么"、"有哪些主题"等全局性问题。`,
    inputSchema: z.object({
      query: z.string().describe("想了解的全局主题或问题"),
      topK: z.number().min(1).max(5).default(3),
    }),
    execute: async ({ query, topK }) => {
      const queryEmbedding = await embedText(query);
      const vectorLiteral = toVectorLiteral(queryEmbedding);

      const reports = await prisma.$queryRawUnsafe(`
        SELECT gcr.id, gcr.title, gcr.summary, gcr."keyFindings", gcr.rating,
               gc.size as "entityCount", gc.level,
               1 - (gcr.embedding <=> '${vectorLiteral}'::vector) as score
        FROM "GraphCommunityReport" gcr
        JOIN "GraphCommunity" gc ON gcr."communityId" = gc.id
        WHERE gcr."userId" = '${userId}'
        ORDER BY gcr.embedding <=> '${vectorLiteral}'::vector
        LIMIT ${topK}
      `);
      return { communities: reports };
    },
  });

  // ═══════════════════════════════════════
  // 6. 搜索笔记
  // ═══════════════════════════════════════
  const search_notes = tool({
    description: `搜索用户的笔记。在标题和内容中查找关键词。适用于"我之前记过XX吗"、"我的笔记里有没有关于XX的内容"。`,
    inputSchema: z.object({
      query: z.string().describe("搜索关键词"),
      category: z.enum(["WORK", "STUDY", "LIFE", "PROJECT"]).optional(),
      topK: z.number().min(1).max(10).default(5),
    }),
    execute: async ({ query, category, topK }) => {
      const notes = await prisma.note.findMany({
        where: {
          userId,
          deletedAt: null,
          ...(category ? { category } : {}),
          OR: [
            { title: { contains: query, mode: "insensitive" } },
            { content: { contains: query, mode: "insensitive" } },
          ],
        },
        take: topK,
        orderBy: { updatedAt: "desc" },
        select: { id: true, title: true, content: true, category: true, tags: true, updatedAt: true },
      });
      return { notes: notes.map(n => ({ ...n, content: n.content.substring(0, 500) })) };
    },
  });

  // ═══════════════════════════════════════
  // 7. 创建笔记
  // ═══════════════════════════════════════
  const create_note = tool({
    description: `为用户创建新笔记。适用于"帮我记录一下"、"保存为笔记"、"创建关于XX的笔记"。`,
    inputSchema: z.object({
      title: z.string().describe("笔记标题"),
      content: z.string().describe("笔记内容（Markdown）"),
      category: z.enum(["WORK", "STUDY", "LIFE", "PROJECT"]).default("WORK"),
      tags: z.array(z.string()).default([]),
    }),
    execute: async ({ title, content, category, tags }) => {
      const note = await prisma.note.create({
        data: { userId, title, content, category, tags },
      });
      return { success: true, noteId: note.id, title: note.title };
    },
  });

  // ═══════════════════════════════════════
  // 8. 构建知识图谱
  // ═══════════════════════════════════════
  const build_graph = tool({
    description: `为知识库文档构建知识图谱索引。从文档中提取实体和关系，构建图谱并生成社区摘要。构建约 1-3 分钟/文档，消耗 LLM token。`,
    inputSchema: z.object({
      documentId: z.string().optional().describe("文档 ID，不传则索引所有未索引文档"),
    }),
    execute: async ({ documentId }) => {
      // 异步触发图谱索引
      const docs = documentId
        ? [await prisma.knowledgeDocument.findUnique({ where: { id: documentId, userId } })]
        : await prisma.knowledgeDocument.findMany({
            where: { userId, status: "COMPLETED", graphIndexed: false },
          });

      if (!docs || docs.length === 0) {
        return { status: "no_docs", message: "没有需要索引的文档" };
      }

      // 触发异步索引（不阻塞响应）
      for (const doc of docs) {
        if (doc) {
          indexDocumentGraph(doc.id, userId).catch(err =>
            console.error(`Graph index failed for doc ${doc.id}:`, err)
          );
        }
      }

      return {
        status: "processing",
        message: `已启动 ${docs.filter(Boolean).length} 个文档的图谱索引任务`,
      };
    },
  });

  // ═══════════════════════════════════════
  // 9. 获取时间
  // ═══════════════════════════════════════
  const get_time = tool({
    description: "获取当前日期和时间。适用于涉及时效性的问题。",
    inputSchema: z.object({}),
    execute: async () => ({
      datetime: new Date().toISOString(),
      timezone: "Asia/Shanghai",
    }),
  });

  return {
    vector_search,
    keyword_search,
    graph_explore,
    graph_search,
    community_summary,
    search_notes,
    create_note,
    build_graph,
    get_time,
  };
}
```

```typescript
// src/app/api/agent-chat/route.ts

import { NextResponse } from "next/server";
import { z } from "zod";
import {
  streamText,
  createUIMessageStream,
  createUIMessageStreamResponse,
} from "ai";
import { chatModel } from "@/lib/ai/dashscope";
import { prisma } from "@/lib/db";
import { getCurrentUserId, unauthorized } from "@/lib/api-helpers";
import { createAgentTools } from "@/lib/agent/tools";

export const maxDuration = 120; // Agent 多步推理需要更长时间

const bodySchema = z.object({
  message: z.string().min(1).max(4000),
  sessionId: z.string().uuid().optional(),
});

export async function POST(req: Request) {
  const userId = await getCurrentUserId();
  if (!userId) return unauthorized();

  // 解析请求体
  let body: z.infer<typeof bodySchema>;
  try {
    const raw = await req.json();
    const parsed = bodySchema.safeParse(raw);
    if (!parsed.success) {
      return NextResponse.json(
        { error: "VALIDATION_ERROR", message: parsed.error.message },
        { status: 400 }
      );
    }
    body = parsed.data;
  } catch {
    return NextResponse.json(
      { error: "INVALID_JSON", message: "请求体格式错误" },
      { status: 400 }
    );
  }

  // 获取或创建会话
  let sessionId = body.sessionId;
  if (sessionId) {
    const existing = await prisma.chatSession.findFirst({
      where: { id: sessionId, userId },
      select: { id: true },
    });
    if (!existing) sessionId = undefined;
  }
  if (!sessionId) {
    const created = await prisma.chatSession.create({
      data: { userId, title: body.message.substring(0, 50) },
    });
    sessionId = created.id;
  }

  // 保存用户消息
  await prisma.chatMessage.create({
    data: { sessionId, role: "USER", content: body.message },
  });

  // 获取对话历史
  const history = await prisma.chatMessage.findMany({
    where: { sessionId },
    orderBy: { createdAt: "asc" },
    take: 20,
  });

  // 获取图谱状态
  const graphEntityCount = await prisma.graphEntity.count({ where: { userId } });
  const hasGraph = graphEntityCount > 0;

  // 创建工具集（注入 userId）
  const tools = createAgentTools(userId);

  // Agent 对话（多步推理 + 流式）
  const result = streamText({
    model: chatModel,
    maxSteps: 5, // 不需要同时设置 stopWhen，maxSteps 已包含此逻辑

    system: buildSystemPrompt(hasGraph),

    messages: [
      ...history.map(m => ({
        role: m.role.toLowerCase() as "user" | "assistant",
        content: m.content,
      })),
      { role: "user" as const, content: body.message },
    ],

    tools,

    onFinish: async ({ text, steps }) => {
      // 收集所有工具调用记录
      const toolCalls = steps.flatMap(step =>
        (step.toolCalls ?? []).map(tc => ({
          toolName: tc.toolName,
          args: tc.args,
        }))
      );

      await prisma.chatMessage.create({
        data: {
          sessionId,
          role: "ASSISTANT",
          content: text,
          sources: JSON.stringify({ toolCalls, answer: text }),
        },
      });

      await prisma.chatSession.update({
        where: { id: sessionId },
        data: { updatedAt: new Date() },
      });
    },
  });

  // 使用与现有 chat API 一致的 UIMessageStream 模式
  const stream = createUIMessageStream({
    execute: async ({ writer }) => {
      writer.merge(result.toUIMessageStream());
    },
  });

  const response = createUIMessageStreamResponse({ stream });
  const headers = new Headers(response.headers);
  headers.set("X-Session-Id", sessionId);

  return new Response(response.body, {
    status: response.status,
    statusText: response.statusText,
    headers,
  });
}
```

### 修正 C：graphExplore 多跳修复（替代第 2.2 节中的实现）

```typescript
// src/lib/graph/search.ts

import { prisma } from "@/lib/db";
import { embedText } from "@/lib/ai/embeddings";

function toVectorLiteral(embedding: number[]): string {
  return `[${embedding.join(",")}]`;
}

export async function graphExplore(
  entityName: string,
  userId: string,
  hops: number,
  relationFilter?: string
) {
  // 1. 模糊匹配实体
  const entity = await prisma.graphEntity.findFirst({
    where: { userId, name: { contains: entityName, mode: "insensitive" } },
  });
  if (!entity) {
    return { found: false, message: `未找到实体 "${entityName}"` };
  }

  // 2. 逐跳遍历
  const visited = new Set<string>([entity.id]);
  const allRelations: Array<{
    hop: number;
    source: string; sourceType: string;
    relation: string;
    target: string; targetType: string;
    description: string; weight: number;
  }> = [];

  let currentEntityIds = [entity.id];

  for (let hop = 0; hop < hops; hop++) {
    const rels = await prisma.graphRelationship.findMany({
      where: {
        userId,
        OR: [
          { sourceEntityId: { in: currentEntityIds } },
          { targetEntityId: { in: currentEntityIds } },
        ],
        ...(relationFilter ? { type: relationFilter } : {}),
      },
      include: { sourceEntity: true, targetEntity: true },
      orderBy: { weight: "desc" },
    });

    const nextEntityIds: string[] = [];
    for (const rel of rels) {
      allRelations.push({
        hop: hop + 1,
        source: rel.sourceEntity.name,
        sourceType: rel.sourceEntity.type ?? "OTHER",
        relation: rel.type ?? "RELATED_TO",
        target: rel.targetEntity.name,
        targetType: rel.targetEntity.type ?? "OTHER",
        description: rel.description,
        weight: rel.weight,
      });

      // ✅ 修正：用 currentEntityIds 判断方向，而非固定的 entity.id
      const otherId = currentEntityIds.includes(rel.sourceEntityId)
        ? rel.targetEntityId
        : rel.sourceEntityId;

      if (!visited.has(otherId)) {
        visited.add(otherId);
        nextEntityIds.push(otherId);
      }
    }
    currentEntityIds = nextEntityIds;
    if (currentEntityIds.length === 0) break; // 无更多邻居，提前终止
  }

  return {
    found: true,
    entity: { name: entity.name, type: entity.type, description: entity.description },
    relations: allRelations,
    totalRelations: allRelations.length,
  };
}
```

```prisma
  communityId String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  user          User                @relation(fields: [userId], references: [id])
  relationships GraphRelationship[] @relation("sourceEntity")
  targetRels    GraphRelationship[] @relation("targetEntity")
  community     GraphCommunity?     @relation(fields: [communityId], references: [id])

  @@index([userId])
  @@index([userId, name])

  @@index([userId])
  @@index([sourceEntityId])
  @@index([targetEntityId])

model GraphCommunity {
```

### 修正 E：图谱数据 API 修正（替代第 6.4.2 节）

```typescript
// src/app/api/knowledge/graph-data/route.ts

import { NextResponse } from "next/server";
import { prisma } from "@/lib/db";
import { getCurrentUserId, unauthorized } from "@/lib/api-helpers";
import { getCommunityColor } from "@/lib/graph/colors";

export async function GET() {
  const userId = await getCurrentUserId();
  if (!userId) return unauthorized();

  const [entities, relationships, communities] = await Promise.all([
    prisma.graphEntity.findMany({
      where: { userId },
      select: {
        id: true, name: true, type: true, description: true,
        degree: true, communityId: true,
      },
    }),
    prisma.graphRelationship.findMany({
      where: { userId },
      select: {
        id: true, sourceEntityId: true, targetEntityId: true,
        type: true, description: true, weight: true,
      },
    }),
    prisma.graphCommunity.findMany({
      where: { userId, level: 0 },
      select: { id: true, size: true },
    }),
  ]);

  // ✅ 修正：使用 getCommunityColor 动态生成颜色
  const allCommunityIds = communities.map(c => c.id);
  const communityColorMap = Object.fromEntries(
    allCommunityIds.map(id => [id, getCommunityColor(id, allCommunityIds)])
  );

  return NextResponse.json({
    nodes: entities.map(e => ({
      key: e.id,
      attributes: {
        label: e.name,
        type: e.type,
        description: e.description,
        degree: e.degree,
        communityId: e.communityId,
        x: Math.random() * 1000,
        y: Math.random() * 1000,
        size: Math.max(3, Math.min(20, (e.degree || 1) * 2)),
        color: communityColorMap[e.communityId ?? ""] || "#999",
      },
    })),
    edges: relationships.map(r => ({
      key: r.id,
      source: r.sourceEntityId,
      target: r.targetEntityId,
      attributes: {
        label: r.type,
        description: r.description,
        weight: r.weight,
        size: Math.max(1, r.weight / 3),
        color: "#ccc",
      },
    })),
    stats: {
      entityCount: entities.length,
      relationshipCount: relationships.length,
      communityCount: communities.length,
    },
  });
}
```
